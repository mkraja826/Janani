# Care+ beta UI milestone

This milestone adds a user-facing Care+ plan surface and a beta assistant screen without enabling purchases or production AI.

## Boundaries

- Entitlement remains server-authoritative.
- No client-side flag can grant Care+.
- Purchase buttons are informational placeholders until Play Billing/RevenueCat is implemented and verified.
- The beta assistant may call the existing Care+ gateway contract, but production AI remains disabled by server configuration.
- Emergency guidance and access to user-entered health records remain free.
- Usage is communicated as monthly feature limits, not raw token counts.

## Launch pricing draft

- Janani Free: ₹0
- Janani Care+: ₹99/month
- Janani Care+ Annual: ₹799/year

These prices are presentation-only in this milestone and must not be treated as active Play Store products.

Public support

A private Janani support and privacy-request channel has not yet been published. The project's GitHub Issues page is public and currently restricts new issue creation.

Do not post sensitive information. Never include an email address, password, family invite code, pregnancy dates or measurements, health or medication details, journal text, message content, access token, device token, or screenshots containing personal data.

Ask for help

General public support is temporarily unavailable while issue creation is restricted. Do not work around that restriction by placing support requests or personal information in commits, pull requests, discussions, or unrelated issues.

View public issue availability

For account removal, use the separate authenticated account-deletion flow; it does not require a support issue. A working private support channel remains a launch requirement.

Security concerns

Do not publish secrets, exploit details, or personal data in the repository. A private security-reporting channel is not yet published, so security reports that require confidential details cannot currently be accepted safely through this site.

Medical concerns

GitHub support cannot provide medical advice or emergency assistance. Contact local emergency services or a qualified maternity-care professional for urgent or medical concerns.
